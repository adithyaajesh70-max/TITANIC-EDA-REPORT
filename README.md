# TITANIC-EDA-REPORT


Task: Exploratory Data Analysis (EDA)
Dataset: Titanic Dataset
Tools: Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

# Analysis

* Data inspection using `info()`, `describe()` and `value_counts()`
* Missing-value analysis
* Histograms, boxplots and scatterplots
* Pairplot and correlation heatmap
* Survival analysis by gender and passenger class

# Key Findings

* Overall survival rate was approximately **38%**.
* Females had a higher survival rate than males.
* First-class passengers had better survival chances.
* Missing values were mainly in **Cabin, Age and Embarked**.
